# Changelog

## 1.0.0
- Release of DYF under the codename **dyf**.
- Disables self-respawn in co-op (2+ players).
- Friend's value is a debt: starts at **-$100**.
- Casino roulette (Variant B): multiplicative **×/÷** with a sign flip at the **$99** buy-out line (Red/Black ×2, Green ×35).
- Corpse is never destroyed on a loss.
- Root-cause fixes that made the mod actually run on **Unity 6** (upgraded BepInEx to 5.4.23.x) and corrected several Harmony patch targets.
- Fixed 2D on-screen bail HUD while hovering/carrying a corpse.
- Spooky dead voice chat filter (pitch, lowpass, echo, reverb).
